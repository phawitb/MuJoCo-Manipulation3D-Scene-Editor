# SO-101 model provenance

Vendored unchanged from [MuJoCo Menagerie / robotstudio_so101](https://github.com/google-deepmind/mujoco_menagerie/tree/f3b6013629c7b94f8ee93fd977b161fa8350f9bc/robotstudio_so101), commit `f3b6013629c7b94f8ee93fd977b161fa8350f9bc`, retrieved 2026-10-24.

Apache-2.0; see `so101/LICENSE` and upstream README/CHANGELOG. All meshes referenced by `so101.xml` are included. Runtime composition changes the fixed base pose and timestep, adds a table, floor, and procedural objects. Robot joint topology, limits, inertias, actuators and authored collision geometry are preserved. The upstream model uses simplified robot collision shapes; these are not exact mesh collisions. Household objects are procedural approximations, not verified commercial product assets.
